# Inspect bestfit appearance flags pass through Python defaults

Inspect `plot bestfit` gains scalar Bestfit appearance flags: `--observed-frame`, `--flux fnu|nufnu|flambda`, `--log x|y|both`, `--linear`, `--no-lines`, `--no-total`, `--no-components`, and `--full-range`. A present flag is passed through to `plot_bestfit`. An omitted flag is not passed, so the Python default remains. That is the opposite of Plot save, where omitting `--save` forces `save=False`. `--log` requires `x`, `y`, or `both`; together with `--linear` it is an error. The same flags on `posterior` are unknown options. We rejected per-component `--hide` because the `show_components` key is the FITS extension name, not the legend label, and a miss still draws the component. We rejected `--linear x|y|both` because `--log x` already leaves y linear (and `--log y` leaves x linear), and the plotter cannot force one axis linear while leaving the other on auto. We rejected path, filter-file, model-name, font, figsize, and dpi controls on Inspect.
