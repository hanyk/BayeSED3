# Emission-line annotation engine: specutils threshold + alfa/PyEMILI percentile continuum

`plot_bestfit(show_residuals=True)` marks only emission lines significantly detected in the observed spectrum (default `min_line_snr=2.5`, `line_window_kms=3000`, falsy disables detection; photometry-only plots keep every line). Detection delegates to `specutils.fitting.find_lines_threshold` on a rolling-25th-percentile continuum-subtracted `Spectrum` carrying the FITS per-pixel errors as `StdDevUncertainty`, then a table line counts as detected when a found emission-line center falls inside its ±`line_window_kms` velocity window. We rejected three alternatives on an SPZLINE-anchored harness (SDSS pipeline per-line Gaussian fits, |LINEAREA/LINEAREA_ERR| ≥ 3 as positive-only reference — SPZLINE fits its full candidate template regardless of presence and omits lines like He I 4922/5015, so it certifies recall but not false-positive rate): (1) a hand-rolled per-line matched filter (inverse-variance windowed SNR via prefix sums, Horne 1986) is statistically stronger and dependency-free but self-maintained and unciteable — it was our first implementation and was replaced when the user asked for existing tooling; (2) `gaussian_smooth` before thresholding collapses recall to 16–53% by diluting narrow-line peaks; (3) integrated `analysis.line_flux` SNR and an empirical-null (annulus-calibrated) matched filter both fail on the 25th-percentile continuum's systematic positive offset, which accumulates over wide windows and inflates everything (noise regions reach 25–33σ), while an annulus null is contaminated by neighboring lines (recall drops to 47%, missing even [O III]5007). The per-pixel specutils criterion keeps 100% recall on the reference lines at 2.5–3σ; its known weakness — per-pixel false positives that scale with pixel count, invisible to the SPZLINE harness and only measurable by injection-recovery — is documented in `tests/test_emission_line_detection.py`, which locks the contract: 100% recall on SPZLINE-significant lines (synthetic-spectrum tests were dropped per user decision; SPZLINE serves as the real-data reference). Detection runs once per band on RAW flux/errors before `flux_unit` conversion so the threshold means the same thing in every unit mode, in the rest frame (observed-frame spectra divide by 1+z; unparseable redshift disables detection with a warning rather than silently mismatching). Future upgrade path if false positives ever matter: injection-recovery with neighbor masking (iterative matched filter) — prior algorithm attempts are preserved in session history, not in code.

Label layout follows the same separation of concerns, with each criterion given its own principled definition instead of a shared magic number: blended-feature GROUPING is a physics criterion in velocity space — a line joins the previous line's group when their rest-frame separation is below `line_window_kms` (reusing the detection window: lines a detector cannot attribute separately are drawn as one feature, labels stacked vertically in one column with same-family members merged, e.g. "[O III]4959,5007"); COLLISION AVOIDANCE is a rendering criterion — a rotated-90° label is ~1.2 × fontsize wide, so the horizontal slot is `1.2 × fontsize / axes-width-in-points` (~2.15% at default figsize/fontsize, scaling automatically), each label taking the lowest column whose last anchor is horizontally clear and columns never drifting rightward. Residual label offsets (≤1 column) occur only where ≥4 labels form one blended feature and vertical stacking reaches the panel-height limit; guide lines (`axvline`) are drawn at the true wavelength for every detected line regardless of label offset. Balmer labels carry vacuum wavelengths ("Hβ 4863") consistent with the other families.
