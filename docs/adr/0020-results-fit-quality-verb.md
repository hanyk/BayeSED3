# Fit quality: a results verb over bestfit FITS residuals, not `plot bestfit --json`

Agents need machine-readable per-object fit diagnostics (residual aggregates, χ², ranked outliers) to judge fit quality and target improvements. The data lives in the bestfit FITS files, not HDF5, but `get_bestfit_spectrum` already establishes that Results methods may load FITS on demand. We add a results verb `bayesed3 results <outdir> fit_quality [--cat] [--cfg] [--obj] [--band EDGES] [--top N] [--sigma T] [--json]` backed by `BayeSEDResults.get_fit_quality(object_id, band_edges=None, top_n=20, sigma_threshold=3.0)`. `--json` reuses the results-verb grammar (always an array, one record per object); the human form prints tables. Residuals are `(obs−mod)/err` on native FITS columns — sigma units, invariant under flux-unit conversion — matching the residual panel in `plot_bestfit`.

**Band segmentation.** Spectroscopy splits by the FITS `iband` column by default; `--band 0.35,0.55,0.9` supplies rest-frame μm boundary points that cut the spectral range into contiguous segments `[min,b1],[b1,b2],…,[b2,max]`, replacing iband grouping. Photometry stays grouped per `band` name and `--band` never touches it. Each dataset record carries `kind`, `label`, `wl_range_rest`, `n`, `chi2`, `chi2_red`, `resid_median`, `resid_rms`, `sigma_threshold`, `frac_outside`, `flags`, and the top-N `outliers` list (obs + rest wavelength, `n_sigma`, ranked by |n_σ| descending — always emitted, independent of `--sigma`, which only gates `frac_outside` and the boolean flags). χ² prefers the header `XMIN²/ND` when present (`chi2_source: "header"`), else computes (`"computed"`); per-dataset χ² is always computed. No bestfit FITS for an object is a one-line error (`No bestfit FITS files found for object …`); FITS without `obs:phot`/`obs:spec` yields `datasets: []` with the header card only.

**Rejected alternatives.** `plot bestfit --json` — plotting verbs produce images (ADR-0017/0018); a JSON mode there would need new grammar for image suppression and multi-object output, all of which results verbs already have. Paired-interval band syntax (`--band a-b`) — allows gaps and doubles the argv for contiguous cuts nobody asked for. Applying `--band` to photometry — photometric points are already per-filter; re-binning them by wavelength loses the filter identity. Prose improvement advice in the payload — interpretation belongs to the calling agent; the CLI emits machine-readable facts (`frac_outside`, ranked outliers, flags like `line_residual_outliers`). Full per-point arrays — spectra reach tens of thousands of points; agents that need them use the Python API. Fixed `frac_outside_3sigma` field name — the threshold is `--sigma`-configurable, so the record carries `sigma_threshold` + a stable `frac_outside` name instead.

**Clarifications (2026.10.08, from code review).** Three corner semantics settled after implementation:

1. **Band segments are a partition**: `[min,b1)`, `[b1,b2)`, …, last segment closed at `[b_{n},max]`. A spectral point exactly on an edge belongs to the right-hand segment only, so no point is ever counted in two segments' `n`/χ²/`frac_outside`.
2. **`line_residual_outliers` fires on spectroscopy datasets only.** The flag marks a point with |n_σ| > `sigma_threshold` within 0.005 μm (rest) of a known emission line (`bayesed/emission_lines.py`, the same table `plot_bestfit` draws). Photometric bandpasses are far wider than that window, so a photometric point is almost always "near" some line — the flag would carry no information. Per-line residual statistics are deliberately not a payload field: `--band` around a line (e.g. `--band 0.655,0.658`) already yields that segment's `n`/χ²/`frac_outside`; a `--lines` shortcut is deferred until real agent usage pulls for it.
3. **A missing bestfit FITS aborts the batch with the one-line error naming the object** (exit 1, no JSON). This is the resolution of the tension with "always an array": an agent cataloging many objects runs the verb per object (or per `--obj` subset) and gets one-line errors it can attribute; silently skipping the object would bury the failure inside a partial payload.
4. **Top-level `chi2` is the total in both branches.** The header card `XMIN²/ND` is already reduced, so when data HDUs are present the total is recovered as `XMIN²/ND × n_total` (`chi2_red` stays the card value); header-only records (no data HDUs) keep the card value for both fields. The computed branch sums per-dataset χ². One key, one unit.
