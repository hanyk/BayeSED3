# Skill happy path: SEDModel + SEDInference → Results

The BayeSED3 agent skill is an workflow router, not an API encyclopedia. Its canonical happy path builds the SED model with `SEDModel`, always calls `SEDInference.priors_init`, optionally `set_prior`, then `inference.run` which returns `BayeSEDResults`. We rejected defaulting to `BayeSEDParams.galaxy()`/`.agn()` plus `BayeSEDInterface.run` (returns `BayeSEDExecution`) because that path underuses prior management, conflates Execution with Results in docs, and is less flexible for mixed components; factories and `Interface.run` remain documented branches for shortcuts and batch/diagnostics.
