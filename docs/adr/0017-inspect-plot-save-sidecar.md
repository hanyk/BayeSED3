# Inspect plot `--save`: boolean sidecar, no path

ADR-0009's path-valued `--out` (file vs directory, one object vs several) made Plot save harder than the need. We decide: `bayesed3 plot` takes boolean `--save` (no value). On: one image per plotted object in that object's Results product directory (`*_bestfit.fits` / sample files), still `show=True`; filenames are not user-chosen. Off: display only — Inspect must not inherit Python plot defaults (`plot_bestfit` and `plot_posterior*` write a sidecar when `save` is omitted). We keep `--save` despite ADR-0009 rejecting that spelling as a *path* flag: collision with binary `--save_*` is first-token (`plot` vs `run`) plus CONTEXT, not argv. We rejected keeping `--out PATH`, making `--out` a valueless boolean, `--save-plot`, always-save with no flag, a path override on top of the sidecar, saving into outdir/HDF5 roots, and changing Python `plot_bestfit()`'s default sidecar behaviour in this cut.

Presentation owns sidecar paths; Inspect only passes `save=`. Bestfit keeps the FITS-stem PNG. Posterior `save=True` without `output_file` writes beside the `*_sample_par` already loaded for GetDist as `{config stem}_{kind}.png` after stripping `_sample_par` (`posterior_free` / `posterior_derived` / `posterior` for `--par`) so kinds do not overwrite. Python `plot_posterior*` defaults to `save=True`, same as `plot_bestfit`. Inspect without `--save` passes `save=False`. We rejected Inspect `_plot_sidecar_path`, a second glob for the PNG path, `{id}_{kind}.png`, `{sample_par stem}_free.png`, a single sample_par-stem PNG for every posterior kind, and leaving posterior save-off while bestfit save-on.
