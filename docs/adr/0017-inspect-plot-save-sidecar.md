# Inspect plot `--save`: boolean sidecar, no path

ADR-0009's path-valued `--out` (file vs directory, one object vs several) made Plot save harder than the need. We decide: `bayesed3 plot` takes boolean `--save` (no value). On: one image per plotted object in that object's Results product directory (`*_bestfit.fits` / sample files), still `show=True`; filenames are not user-chosen. Off: display only — Inspect must not use `plot_bestfit`'s Python default of writing a PNG next to the FITS when `output_file` is omitted. We keep `--save` despite ADR-0009 rejecting that spelling as a *path* flag: collision with binary `--save_*` is first-token (`plot` vs `run`) plus CONTEXT, not argv. We rejected keeping `--out PATH`, making `--out` a valueless boolean, `--save-plot`, always-save with no flag, a path override on top of the sidecar, saving into outdir/HDF5 roots, and changing Python `plot_bestfit()`'s default sidecar behaviour in this cut.
