# Skill refs: default zero; Prefer `run` restated in ADR-0014

Skill eval Phase 2 showed Prefer entry selection was reliable, but agents opened `binary-cli.md` / extra model refs on ordinary `SEDInference` fits (weak context pointers). We decide: default new fit uses `SKILL.md` Skeleton + FAQ with **zero** `skills/references/*` opens; open a ref only when its stated gate fires. Prefer `run` / `binary-cli.md` gates are the three clauses in ADR-0014 (not “the skill text mentioned `bayesed3 run`”). Sampling knobs (`nlive` / `seed` / `efr` / `Ntest`) live in the FAQ (quick test) and `advanced-run-modes.md` (when to change beyond the FAQ) on the Python path; slot meanings are `multinest-params.md` (ADR-0015 gate); after a Prefer `run` gate, tuple *order* is live `--help` plus the `binary-cli.md` index. We rejected “open any tree-listed ref by default” (fan-out) and stuffing a full API encyclopedia into the skill (ADR-0001). Executable pointer table: `skills/SKILL.md`.
