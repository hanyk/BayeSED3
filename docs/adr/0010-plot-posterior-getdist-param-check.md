# Plot posterior params vs GetDist samples

`plot_posterior` must not assume HDF5 / `.paramnames` free-or-derived names are all present in GetDist `MCSamples` (fixed parameters such as `z` are often dropped). Explicit `params` fail the whole plot with `ValueError` listing missing names (`parameter(s) not in posterior samples: …`). When `params` is omitted, and for `plot_posterior_free` / `plot_posterior_derived`, keep only names that exist in that samples object and have variance above a small ε, then (for derived) apply `max_params`; if none remain, `ValueError`. Resolution is always by parameter name on one samples object—never by aligning free-list index to sample columns. We rejected failing default/free plots on missing names, silently dropping explicit misses, and Available-list error text for this case.
